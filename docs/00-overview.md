# 00 · 项目概述

## 背景

`blood-pressure-measurement` 是一个面向基层体检/公卫现场的 Windows 桌面应用，运行在
体检一体机或工作站上，负责：

- 通过串口读取血压计数据；
- 通过 VGA2USB 采集卡（Epiphan）采集 B 超影像；
- 录入/选择诊断结论，套用 Word 模板生成 B 超报告；
- 数据本地入库（SQLite），并在联网时上传到服务器；
- 支持应用自动更新与设备驱动安装。

现有实现基于 Electron 31，**无法运行在 Windows 7，且官方 32 位支持也已随版本演进而受限**。
现场存在大量 Win7 / 32 位机器，因此需要重构。

## 目标

| 编号 | 目标 | 说明 |
| --- | --- | --- |
| G1 | 支持 Windows 7 SP1 | 可正常运行、安装、采集、上传 |
| G2 | 支持 32 位（ia32） | 可安装、可运行、原生依赖可加载 |
| G3 | 业务不回归 | 血压/B超/报告/上传/更新全部保留 |
| G4 | 可维护 | 分层清晰、类型完整、构建可重复 |
| G5 | 可交付 | 可产出 Win7 可用的 NSIS 安装包 |
| G6 | 数据目录可选 | 安装时可选数据存储目录，应用内可更换 |
| G7 | 数据可迁移 | SQLite + 图片 + 报告可安全换盘，不丢数据 |
| G8 | 布局优化 | 统一设计系统，**血压测量界面与字体零回归** |

## 非目标（本期不做）

- 不新增业务功能（如云端管理、更多设备型号）。
- **不修改后端接口**（接口、字段、鉴权契约全部冻结）。
- 不重做血压测量页的视觉与交互（仅替换其内部 IPC 调用）。
- 不迁移到非 Electron 的桌面方案（除非 ADR 决定）。
- 不支持 Windows XP / Vista。

## 范围

**包含**

- 主进程：数据库、串口、USB、视频设备、报告生成、更新、驱动安装、日志、窗口管理。
- 预加载：contextBridge 暴露的安全 API。
- 渲染进程：登录、血压测量、血压历史、B超采集、B超历史、模板管理、设置、更新。
- **数据存储**：安装时选择目录、应用内更换目录、数据迁移与容量管理。
- **界面**：血压测量页视觉保留，其余页面统一设计系统重构。
- 构建：electron-builder 产出 Win7/32 位 NSIS 包。

**不包含**

- 服务端接口（沿用现有服务端）。
- 硬件固件与驱动本身的改造（仅做调用与安装编排）。

## 名词约定

| 名词 | 含义 |
| --- | --- |
| 血压计 | USB 转串口设备，VID `1A86` / PID `7523`（CH340/CH341 类） |
| VGA2USB | Epiphan 视频采集卡，用于把 B 超机 VGA 信号转 USB 视频 |
| 公卫 / GW | 国家基本公共卫生服务体检场景 |
| 商业 / BS | 商业体检场景 |
| 主进程 | Electron main process |
| 渲染进程 | Electron renderer process |
| 预加载 | Electron preload script |
