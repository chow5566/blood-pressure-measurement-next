# 12 · 现场排障手册

> 面向实施/运维，按现象定位。日志与引导日志位置见 §1。

## 1. 日志位置

| 日志 | 路径 | 说明 |
| --- | --- | --- |
| 主进程日志 | `%APPDATA%\blood-pressure-measurement\logs\main.log` | electron-log，含数据库/存储/IPC/错误 |
| 引导日志 | `%TEMP%\blood-pressure-measurement-boot.log` | 启动极早期同步写入，主进程日志为空时看这里 |
| 配置 | `%APPDATA%\blood-pressure-measurement\config.json` | dataDir / baseApi / renderMode / username |

采集方法：`Win+R` 打开上述目录，打包 `logs` 与 `boot.log`。

## 2. 启动类

### 2.1 应用无法启动 / 闪退
- 确认 **Windows 7 SP1**，并安装补丁：`KB4474419`、`KB4490628`、`KB3063858`/`KB2533623`。
- 安装 **VC++ 2015-2022 运行库（x86 与 x64）**。
- 查看引导日志是否有 `bootstrap failed` 记录。

### 2.2 白屏 / 花屏 / 界面错乱
- 设置页将「渲染模式」改为**软件渲染**并重启（等价 `app.disableHardwareAcceleration()`）。
- 或删除/修改 `config.json` 中 `"renderMode": "software"`。

### 2.3 窗口空白且无报错
- 检查 `config.json` 的 `dataDir` 指向的目录是否存在且可写；
- 引导日志若在 `data dir resolved` 后中断，多为目录权限/掉盘问题。

## 3. 设备类

### 3.1 血压计无法识别
- 设备管理器确认 USB 转串口（CH340/CH341）驱动已装；未装装 CH341SER。
- 设备 VID/PID 必须为 `1A86` / `7523`（程序按此过滤）。
- 串口被其它程序占用会打开失败；关闭占用程序或重插。
- 点击「重新识别血压计」，或「手动识别」。

### 3.2 血压测量无数据 / 超时
- 8 秒无数据会提示「测量结果超时」，重新启动测量即可。
- 指令发送失败时按提示重插 USB。

### 3.3 VGA2USB 无图像
- 设置页安装 **VGA2USB 驱动**（需管理员，首次会弹 UAC）。
- 确认采集卡被系统识别为视频输入设备；在采集页「重新加载」并选择设备。
- 摄像头隐私/设备被占用：关闭其它使用摄像头的程序。

## 4. 存储类

### 4.1 磁盘空间不足
- 顶部/弹窗会提示低空间；低于硬阈值会**禁止新采集入库**。
- 进入「数据存储」→ 更改存储位置，迁移到空间充足的本地固定磁盘。

### 4.2 迁移失败
- 仅支持**本地固定磁盘**，不要选 U盘/移动硬盘/网络盘。
- 目标目录必须为空；迁移期间请勿操作或关闭应用。
- 失败会自动回滚（原数据不动），可重试。

### 4.3 数据目录不可用
- 目录被删除/盘符丢失：打开应用会提示；在设置中重新选择目录或恢复磁盘。
- 只读/权限不足：更换到可写目录。

## 5. 网络类

### 5.1 登录失败
- 检查设置中「服务端地址」是否正确、网络是否可达。
- 查看主进程日志中 `login failed` 具体信息。

### 5.2 上传失败
- 未登录时不会上传，数据保存本地并标记「未上传」。
- 在「B超历史」/血压历史中可重试上传。
- 上传失败不影响本地数据完整性。

## 6. 更新类

- 检查更新失败：确认更新源地址（electron-builder publish）可达。
- 若启用签名校验，需 SHA-2 证书；无签名环境下自动校验可能导致更新报错，需关闭 `publisherName` 校验。

## 7. 快速诊断清单

1. 看引导日志 → 是否启动到 `main window created`。
2. 看主进程日志 → 是否有 `bootstrap failed` / 设备 / 存储错误。
3. 看 `config.json` → `dataDir` 是否正确、`renderMode` 是否需要切软件渲染。
4. 设备管理器 → 串口/CVBS 设备是否识别、驱动是否安装。
5. 设置页 → 服务地址、驱动状态、更新状态。
